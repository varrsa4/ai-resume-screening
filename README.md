# AI Resume Screening Application

## 🚀 Live Demo

Frontend: https://resume-ui-virid.vercel.app
Backend: https://ai-resume-screening-l7hl.onrender.com

---

## 📌 Features

* Upload Resume (PDF/DOC)
* Enter Job Description
* AI analyzes resume
* Displays:

  * Match Percentage
  * Matched Skills
  * Missing Skills
  * Summary

---

## 🛠️ Tech Stack

* Frontend: React.js
* Backend: Node.js + Express.js
* AI: OpenAI / Gemini API

### Deployment:

* Frontend → Vercel
* Backend → Render

---

## ⚙️ Setup Instructions

### 1. Clone Repository

git clone https://github.com/varrsa4/ai-resume-screening

### 2. Backend Setup

cd ai-resume-screening
npm install
npm start

### 3. Frontend Setup

cd resume-ui
npm install
npm start

---

## 🤖 AI Workflow

1. Resume is uploaded
2. Text is extracted
3. Job description is provided
4. AI compares resume with job description
5. Outputs:

   * Match Percentage
   * Skills Analysis
   * Summary

---

## ✅ Conclusion

This application helps recruiters quickly screen resumes using AI, reducing manual effort and improving hiring efficiency.
