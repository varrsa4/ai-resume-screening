## 📌 Features

* Upload Resume (PDF/DOC)
* Enter Job Description
* AI analyzes resume
* Shows:

  * Match Percentage
  * Matched Skills
  * Missing Skills
  * Summary

---

## 🛠️ Tech Stack

Frontend: React.js
Backend: Node.js + Express
AI: OpenAI / Gemini API
Deployment:

* Frontend → Vercel
* Backend → Render

---

## ⚙️ Setup Instructions

### 1. Clone repo

git clone https://github.com/your-username/ai-resume-screening

### 2. Backend

cd ai-resume-screening
npm install
npm start

### 3. Frontend

cd resume-ui
npm install
npm start

---

## 🤖 AI Workflow

1. Resume is uploaded
2. Text is extracted
3. Job description is taken as input
4. AI compares resume with JD
5. Returns:

   * Match %
   * Skills
   * Summary
